
## Depois do Prompt A: instalar no celular (você)

1. No **Chrome do Android**, abra `https://eclirbarroso19-stack.github.io/system/`.
2. Toque em **INSTALAR O SYSTEM**, em Ajustes, ou use o menu ⋮ → **Instalar app** / **Adicionar à tela inicial**.
3. O ícone do portal com a runa S aparece na tela inicial. Abra por ele: o app abre em tela cheia, sem a barra do Chrome.
4. Se você testou com dados de verdade (sem `?teste=1`), vá em Ajustes → **APAGAR TUDO** para começar a jornada do zero.
5. Faça o **Despertar Rápido de verdade**, com honestidade.
6. Faça o **primeiro backup** e guarde o arquivo fora do celular também (Google Drive ou WhatsApp para você mesmo).
7. **Teste sem internet:** ative o modo avião e abra o app. Tem que funcionar.

## Especificação para o Claude Code

Antes de começar: marque 1.7 = 🔄.

### 1.7.a Instalação

- Capture `beforeinstallprompt`.
- Em Ajustes, mostre o botão **INSTALAR O SYSTEM** quando disponível.
- Se o app já estiver instalado (`display-mode: standalone`), mostre "App instalado ✓".
- Peça `navigator.storage.persist()` de novo depois de instalar.
- **Commit.**

### 1.7.b Revisão geral

- **Telas:**
  - percorra todas as telas em larguras de 320, 360 e 412 px: nada pode estourar nem exigir rolagem para o lado;
  - botões com no mínimo 48 px;
  - contraste legível.
- **Service worker:** confira se o cache inclui **todos** os arquivos atuais (liste a pasta e compare com o array do `sw.js`).
- **Erros e logs:**
  - capture erros globais (`window.onerror`, `unhandledrejection`) e mostre `[ERRO DO SISTEMA: <mensagem curta>]` com um botão para copiar os detalhes, para o Eclir colar no Prompt B;
  - remova os `console.log` de depuração.
- **Dados de teste:** confira se o modo `?teste=1` nunca toca no banco real.
- **Desempenho:** com o banco de teste cheio (botão GERAR DADOS FICTÍCIOS), as telas abrem em menos de 1 s.
- Corrija tudo que encontrar.
- **Commit** a cada grupo de correções.
