# Etapa 1.2: Memória do app + Backup

| | |
|---|---|
| **Objetivo** | O app guarda os dados no celular de forma segura e permite salvar e restaurar tudo em um arquivo |
| **Entrega** | Banco IndexedDB com todas as gavetas (stores), migração, Backup/Restaurar, "Apagar tudo", lembrete de backup na sexta |
| **Dias** | ~2 |
| **Livro** | 0 (princípio 7), 16.1, 16.4 (riscos 9 e 10) |

**Analogia:** é o paneiro onde o Sistema guarda tudo. O backup é a cópia que você leva para outro lugar: se o paneiro cair no rio, você não perde a farinha.

## Checklist: está pronto?

- [ ] Em F12 → **Application → IndexedDB → system**, aparecem as 20 gavetas (stores)
- [ ] Em Ajustes → **Fazer backup**, baixa um arquivo `system-backup-AAAA-MM-DD.json`
- [ ] **Mova o backup para fora da pasta `system`**, por exemplo para `Documentos\SYSTEM-backups`. Ele nunca pode ir para o GitHub
- [ ] Em **Restaurar**, escolher o arquivo devolve os dados, e antes disso o Sistema baixa uma cópia de segurança do estado atual
- [ ] **Apagar tudo** pede para digitar `APAGAR` e deixa o app novinho
- [ ] Em Ajustes aparece "Memória protegida: SIM" (no celular pode aparecer só depois de instalar, na 1.7)

## Especificação para o Claude Code

Antes de começar: marque 1.2 = 🔄 no PAINEL.

### 1.2.a Banco (`js/nucleo/db.js`)

- Abra o banco `NOME_BANCO` na versão `VERSAO_DADOS`.
- No `onupgradeneeded`, crie **todas** as stores da tabela do `CLAUDE.md` seção 7, com as chaves indicadas.
  - Índice `dia` em: `eventos`, `ouro`, `treinos`, `checkins` e `diagnosticos`.
  - Índice `quando` em `eventos`.
- **API em Promises:**
  - `obter(store, chave)`
  - `salvar(store, objeto)` (put)
  - `adicionar(store, objeto)` (add, devolve o id)
  - `listar(store)`
  - `listarPorDia(store, dia)`
  - `listarEntreDias(store, inicio, fim)`
  - `apagar(store, chave)`
  - `limparTudo()`
  - `exportarTudo()`
  - `importarTudo(objeto)`
- **Modo de teste:** se a URL tiver `?teste=1`, use o banco `system-teste`. Assim o Eclir testa sem sujar os dados reais.
  - Mostre uma faixa amarela `MODO DE TESTE` no topo.
- **Commit.**

### 1.2.b Migrações (`js/nucleo/migracoes.js`)

- Lista `MIGRACOES = []`, onde cada item tem o formato `{de, para, transformar(dadosExportados)}`.
- Função pura `migrarDados(dados)`: aplica em ordem as migrações que faltam até `VERSAO_DADOS`.
  - É usada ao restaurar um backup antigo e, nas próximas versões, no `onupgradeneeded`.
- Regra escrita no topo do arquivo: **migração nunca apaga dados**.
- **Teste:** um backup com `versaoDados: 1` passa sem mudanças.
- **Commit.**

### 1.2.c Backup (`js/nucleo/backup.js` + Ajustes)

- **Formato:** `{ app: "SYSTEM", versaoDados, versaoApp, exportadoEm (data local legível), stores: { nome: [registros] } }`.
- **`validarBackup(obj)`:** função pura que devolve `{ok, erro}`. Recusa quando:
  - `app` é diferente de "SYSTEM";
  - `versaoDados` é maior que a atual;
  - faltam stores.
- **Exportar:**
  - Blob + `<a download>`, com o nome `system-backup-AAAA-MM-DD.json` (data local);
  - grava `meta.ultimoBackup`;
  - mostra `[MEMÓRIA DO SISTEMA PROTEGIDA.]`.
- **Restaurar:**
  - `<input type=file accept=".json">` → validar → modal `[ATENÇÃO: OS DADOS ATUAIS SERÃO SUBSTITUÍDOS.]`;
  - antes de substituir, **exporta automaticamente** uma cópia do estado atual;
  - depois `migrarDados` → `importarTudo` → recarrega.
- **Apagar tudo:** modal pedindo para digitar `APAGAR` → `limparTudo()` → recarrega.
- **Lembrete da sexta:**
  - se hoje é sexta (dia do jogo) e o último backup tem mais de 6 dias (ou nunca foi feito), mostre ao abrir o app `[DIA DO CONSELHO. FAÇA O BACKUP DOS SEUS DADOS.]` com o botão **FAZER BACKUP**;
  - mostre só 1 vez por dia.
- **Tela de Ajustes, nesta ordem:**
  1. Memória: protegida SIM/NÃO
  2. Último backup
  3. Botões FAZER BACKUP e RESTAURAR
  4. Avisos
  5. Versão
  6. Zona de perigo: APAGAR TUDO
- **Commit.**

### 1.2.d Persistência e abertura

- Na primeira abertura: `navigator.storage.persist()`. Grave `meta.instaladoEm` e atualize `meta.ultimaAbertura` sempre.
- **Utilitários de dinheiro** em `js/nucleo/formato.js` (puros):
  - `formatarReais(centavos)` → `"R$ 1.234,56"`;
  - `lerReais("12,50")` → `1250` (aceita vírgula ou ponto e ignora "R$" e espaços);
  - `formatarData(dia)` → `"21/11/2026"`;
  - `nomeDiaSemana(dia)`.
- **Testes:** formato de dinheiro (incluindo 0, 5, 100000 e valores negativos), `lerReais` com entradas variadas, `validarBackup` (válido, app errado, versão futura) e `migrarDados`.
- **Commit.**
